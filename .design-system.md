# KDG Design System — Keep Dishes Going

> Single source of truth for all frontend styling. Tokens live in `src/css/tokens.css` as CSS custom properties. No gradients. One accent color. Off-black/off-white only (no pure #000/#fff).

---

## 1. Color

### Neutrals (slate family, cool grey)
| Token | Value | Use |
|---|---|---|
| `--bg` | `#F8FAFC` | App background |
| `--surface` | `#FFFFFF` | Cards, nav, modals |
| `--surface-sunken` | `#F1F5F9` | Inset areas, table stripes, skeletons |
| `--border` | `#E2E8F0` | Default borders, dividers |
| `--border-strong` | `#CBD5E1` | Input borders, hover borders |
| `--text` | `#0F172A` | Primary text (off-black) |
| `--text-muted` | `#475569` | Secondary text (AA on white) |
| `--text-subtle` | `#94A3B8` | Placeholders, disabled (decorative only) |

### Accent (terracotta — ONE accent, locked)
| Token | Value | Use |
|---|---|---|
| `--accent` | `#C2410C` | Primary actions, links, active states (white text on it = 4.6:1 AA) |
| `--accent-hover` | `#9A3412` | Hover/active on primary actions |
| `--accent-soft` | `#FFF7ED` | Accent-tinted backgrounds (badges, selected rows) |
| `--accent-ring` | `#FDBA74` | Focus ring |

### Semantic (status only — never decorative)
| Token | Value | Use |
|---|---|---|
| `--success` | `#15803D` | Open, accepted, delivered, in-stock |
| `--success-soft` | `#F0FDF4` | Success badge bg |
| `--warning` | `#B45309` | Pending, preparing, claimed |
| `--warning-soft` | `#FFFBEB` | Warning badge bg |
| `--danger` | `#B91C1C` | Rejected, closed, errors, out-of-stock |
| `--danger-soft` | `#FEF2F2` | Danger badge bg, error boxes |
| `--info` | `#1D4ED8` | In-transit, informational |
| `--info-soft` | `#EFF6FF` | Info badge bg |

### Shadows (slate-tinted, never pure black)
```
--shadow-sm: 0 1px 2px rgba(15, 23, 42, .06)
--shadow-md: 0 4px 12px rgba(15, 23, 42, .08)
--shadow-lg: 0 12px 32px rgba(15, 23, 42, .14)
```

## 2. Typography

System stack (deterministic, zero network): 
`--font: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif`
`--font-mono: ui-monospace, "SF Mono", "Cascadia Mono", Menlo, monospace` — numbers, prices, order IDs.

Scale (1.25 ratio), weight, leading:
| Token | Size/Height | Weight | Use |
|---|---|---|---|
| `--text-xs` | 12/16 | 500 | Badges, table meta, captions |
| `--text-sm` | 14/20 | 400 | Secondary body, form help |
| `--text-base` | 16/24 | 400 | Body, inputs, buttons |
| `--text-lg` | 20/28 | 600 | Card titles, section heads |
| `--text-xl` | 25/32 | 700 | Page titles |
| `--text-2xl` | 31/38 | 700 | Dashboard numbers, hero price |
| `--text-3xl` | 39/47 | 800 | Rare: empty-state headline |

Weights: 400 regular, 500 medium, 600 semibold, 700 bold, 800 extrabold. Tracking: default 0; `-0.02em` on `xl`+; `0.02em` uppercase on badge/eyebrow text (`--text-xs` uppercase only).

## 3. Spacing & Layout

4px base: `--space-1:4  --space-2:8  --space-3:12  --space-4:16  --space-6:24  --space-8:32  --space-12:48  --space-16:64`

Layout:
- Container: `max-width: 1200px; margin-inline: auto; padding-inline: var(--space-4)`
- App nav: height 64px, sticky, `--surface` bg + `--border` bottom, z-index 200
- Page section gap: `var(--space-8)` vertical
- Card grid: CSS Grid `repeat(auto-fill, minmax(300px, 1fr))`, gap `var(--space-4)` — never flex-percent math
- Form column: `max-width: 480px`

### Breakpoints
| Name | Min-width |
|---|---|
| `sm` | 640px |
| `md` | 768px |
| `lg` | 1024px |
| `xl` | 1280px |

Mobile-first. Multi-column collapses to single column below `md`. Nav collapses to hamburger below `md`.

## 4. Shape & Borders

ONE radius system (documented rule, applied everywhere):
| Token | Value | Use |
|---|---|---|
| `--radius-sm` | 6px | Badges, chips, small elements |
| `--radius-md` | 8px | Buttons, inputs, dropdowns |
| `--radius-lg` | 12px | Cards, modals, images |
| `--radius-pill` | 999px | Status dots, step indicators, quantity steppers |

Borders: 1px `--border` default. 2px only for focus ring offset. No borderless-on-bg-white cards over `--surface` (invisible) — cards sit on `--bg` with `--surface` fill.

## 5. Components

### Buttons
- Base: height 40px, `padding-inline: var(--space-4)`, `--radius-md`, `--text-base` weight 600, `transition: background var(--dur-fast) var(--ease), transform var(--dur-fast) var(--ease)`
- `:active` → `transform: translateY(1px)` (tactile push)
- `:focus-visible` → 2px `--accent-ring` outline, 2px offset. Never remove outline without replacement.
- **Primary**: bg `--accent`, text `#FFF7ED` (off-white), hover `--accent-hover`. Label max 3 words, never wraps.
- **Secondary**: bg `--surface`, border `--border-strong`, text `--text`, hover border `--accent`.
- **Ghost**: transparent, text `--accent`, hover bg `--accent-soft`.
- **Danger**: bg `--danger`, text off-white.
- Disabled: `opacity: .5`, `cursor: not-allowed`, no transform.

### Cards
- `--surface` bg, 1px `--border`, `--radius-lg`, `padding: var(--space-6)`, `--shadow-sm`
- Interactive card hover: `--shadow-md` + `border-color: var(--border-strong)` + `translateY(-2px)`. Only if clickable.

### Inputs
- Height 40px, `--radius-md`, 1px `--border-strong`, `padding-inline: var(--space-3)`, bg `--surface`
- Label ABOVE input (`--text-sm` weight 500). Helper text below (`--text-sm` `--text-muted`). Error below in `--danger`.
- Focus: border `--accent` + 2px `--accent-ring` ring. Placeholder never as label.
- Invalid: border `--danger`, error text `--danger` `--text-sm`.

### Badges (order/dish/delivery status)
- `--radius-sm`, `padding: 2px var(--space-2)`, `--text-xs` weight 600 uppercase, letter-spacing 0.02em
- Color = semantic pair: `success/danger/warning/info` text on matching `-soft` bg. One status = one color everywhere.

### Modal
- Overlay: `rgba(15, 23, 42, .5)`, z-index 300. Panel: `--surface`, `--radius-lg`, `--shadow-lg`, `max-width: 480px`, `padding: var(--space-6)`
- Enter: overlay fade 150ms + panel `scale(.96)→1` 200ms `--ease-out`. Esc closes. Focus trapped inside.

### Toast
- Bottom-right, z-index 500, `--radius-md`, `--shadow-md`, `--text` on `--surface` with 3px left border in semantic color. Auto-dismiss 4s, slide-in from right 200ms.

### Skeletons
- `--surface-sunken` blocks matching final layout shape, `--radius-md`, pulse opacity 1→.55→1 1.4s. No spinners for content areas; spinner only inside buttons during submit.

### Tables (owner/driver/admin lists)
- Full-width, `--text-sm`, header `--text-xs` uppercase `--text-muted`, row border-bottom `--border`, row hover `--surface-sunken`
- Numbers/prices right-aligned `--font-mono`. Status = badge. Actions = ghost buttons right-aligned.

### Empty states
- Centered, `--space-12` padding, `--text-3xl` optional headline, `--text-muted` body, one primary CTA. No dead-end pages.

## 6. Motion Tokens

```
--dur-fast: 120ms      hover, focus, press
--dur-med: 200ms       toasts, badges, small reveals
--dur-slow: 300ms      page transitions, modals
--ease: cubic-bezier(.16, 1, .3, 1)     standard out
--ease-in: cubic-bezier(.7, 0, .84, 0)
```

Rules:
- Animate ONLY `transform` + `opacity`.
- Page transition: outgoing view `opacity→0, translateY(-4px)` 120ms `--ease-in`; incoming `opacity 0→1, translateY(8px→0)` 300ms `--ease`.
- Cart add: item row enters `opacity 0→1, translateY(8px)→0` 200ms; quantity number pops `scale(1.2)→1` 120ms.
- Status change: badge cross-fades 200ms + background flash `--accent-soft` 300ms on updated row.
- `@media (prefers-reduced-motion: reduce)`: all durations → 0.01ms. Non-negotiable.

## 8. Accessibility Floor

- Contrast: body text ≥4.5:1, large text ≥3:1. Audit every accent-on-white and white-on-accent pairing.
- Every interactive element keyboard reachable, visible `:focus-visible` ring.
- Status never color-only: badge always pairs color + text label.
- Icon-only buttons carry `aria-label`. Modals `role="dialog"` `aria-modal`. Toasts `role="status"`.
- Form errors linked via `aria-describedby`; inputs `aria-invalid` when errored.
- Hit targets ≥ 40×40px.
